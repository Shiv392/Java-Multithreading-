⭐⭐⭐ What is ExecutorService ==========>
ExecutorService ek interface hai jo thread pool ko manage karta hai aur tasks execute karne ki responsibility leta hai.
Tum thread nahi banate.
Tum sirf task dete ho.

ExecutorService decide karta hai:
Kis thread ko task dena hai.
Kab execute karna hai.
Thread ko reuse karna hai.

Without ExecutorService : 
Tum abhi tak aise code likh rahe the.
Thread t1 = new Thread(new Counter());
Thread t2 = new Thread(new Counter());

t1.start();
t2.start();

Problems:
Thread manually create karna
Thread manually start karna
Thread lifecycle khud manage karna

With ExecutorService
ExecutorService executor = Executors.newFixedThreadPool(2);
executor.execute(new Counter());
executor.execute(new Counter());
executor.shutdown();

Observe karo.
Tumne ek bhi
new Thread(...)
nahi likha.
Java internally thread pool create karegi.

⭐⭐⭐ Internal Working ===============>
ExecutorService executor = Executors.newFixedThreadPool(2);

Worker-1 → Task3

               Queue

Real World Example : Suppose tum Notification Service bana rahe ho.
1000 users ko mail bhejna hai.

Galat ❌
for(User user : users){
    Thread t = new Thread(() -> sendMail(user));
    t.start();
}
1000 threads 😅

Sahi
ExecutorService executor = Executors.newFixedThreadPool(20);
for(User user : users){
    executor.execute(() -> sendMail(user));
}

20 workers.
1000 emails.
Threads reuse honge.
Server stable rahega.

⭐⭐⭐ ExecutorService Method  ================>
1 : Create Executor Service -------------> newFixedThreadPool(numbers)
create Thread pool of 3 workers; 
ExecutorService executor = Executors.newFixedThreadPool(3);
Now here if thread pool size is 3 and request comes 10 so onnly 3 thread will be 
given to do task other will wait in the queue so that completing their task 
worker again pick from thread pool.

2 : execute() ----------->
executor.execute(new Counter());
or
executor.execute(()-> //business logic);

What does execute() do ? 
Give a task to ExecutorService, then it will get done using available threads.
executor.execute(new Counter());
Here executor service will create therad to do the task 
Returns : Noting 
Here execute() dont return value it simply show avaiale thread will do the job in the background.
and not expecting any result ⭐⭐⭐
Email
executor.execute(new SendEmailTask());

Why execute() instead of Thread?
execute() thread create nahi karta. Wo thread pool ke existing threads reuse karta hai.

3. submit() -----------> Returns future object. Use with Runnable and Callable 
Future<?> future = executor.submit(new Counter());
submit() bhi task ExecutorService ko deta hai, lekin ye task ka ek handle (Future) return karta hai.
Matlab:
Task
   ↓
ExecutorService
   ↓
Execute
   ↓
Future (Result Handle)

execute() vs submit() ----------->
execute()	submit()
void return karta hai	Future return karta hai
Sirf Runnable	Runnable + Callable
Result nahi milta	Result mil sakta hai
Fire-and-forget	Result track kar sakte ho

submit() kab use karte hain ? Jab:
Result chahiye.
Task complete hone ka wait karna hai.
Exception ko track karna hai.

Example:
Image upload → URL return
Database insert → Generated ID
PDF generate → File path
Payment → Transaction ID

4. shutdown() ------------->
executor.shutdown();
Kya karta hai?
✅ Naye tasks accept nahi karega.
✅ Jo tasks already queue me hain, unhe complete karega.
✅ Fir thread pool band ho jayega.
Flow:
Task1 ✅
Task2 ✅
Task3 (Queue) ✅
↓
shutdown()
↓
No New Task
↓
Pool Closed

Real World:
Office bol deta hai: "Aaj ke baad koi naya kaam mat lena, jo current kaam hai wo complete karo."

5. shutdownNow() --------->
executor.shutdownNow();
Kya karta hai?
❌ Running tasks ko interrupt karne ki koshish karta hai.
❌ Queue wale tasks execute nahi honge.
❌ Immediately shutdown ki request karta hai.
Flow:
Task1 (Running) ⚠ Interrupt
Task2 (Running) ⚠ Interrupt
Task3 (Queue) ❌ Cancel
Task4 (Queue) ❌ Cancel

Real World:
Office me fire alarm baj gaya. Sab kaam chhodo aur bahar niklo. 🚨
⚠️ Note: Running task tabhi rukega jab wo interrupt ko handle kare.

6. awaitTermination() ----------->
executor.shutdown();
executor.awaitTermination(5, TimeUnit.SECONDS);

Kya karta hai? Current thread wait karta hai.
Shutdown
↓
Wait Maximum 5 Seconds
↓
Sab Task Complete?
Yes → Continue
No → Timeout

Real World:
Boss: "Main ghar tab jaunga jab maximum 5 minute tak employees ka kaam complete ho jaye."
