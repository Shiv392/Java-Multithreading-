#There are several methods in the thread.

1. start() -> call run() inside the thread class.
2. run() -> actual business logic inside the thread that executes.
3. sleep(time millisecond) -> make thread stop for the given time.
4. join() -> wait current thread to get completed first.
5. wait() --> puts thread in thread mode but also release lock.

#Differenec between sleep() and wait() : 
both used to put the thread on sleep but in sleep();
synchronized(lock) {
    Thread.sleep(5000);
}
It will not release the lock so that other thread have to wait for their sleep also.

Now wait();
lock.wait();

it simply says "I can't do this work right now, let me wait". It also releases the lock.
synchronized(lock){
    lock.wait();
}
lock.wait() call hua, Thread WAITING state me chala gaya. Lock release kar diya. Ab koi aur thread lock acquire kar sakta hai.
